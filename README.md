# ipl-match-analysis
IPL Match and Players Performance Analysis using MySQL, Python, and Power BI

Analyzed IPL match and delivery data (2008-2022) to uncover team, 
player, and match-level insights.

## Tech stack
- MySQL — relational database for raw match/delivery data
- Python + SQLAlchemy — ETL pipeline to load and clean data
- Power BI — interactive dashboard for visualization

## What's inside
- 15 SQL queries (basic to advanced) covering joins, aggregations, 
  window functions, and subqueries
- Python script for database connection and data loading
- Power BI dashboard with KPIs, team/player performance, and 
  match trend analysis

  ## Dataset
  Source: [IPL Complete Dataset - Kaggle](https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020)
  Note: Analysis covers IPL seasons 2007/08 to 2022 (950 matches).
